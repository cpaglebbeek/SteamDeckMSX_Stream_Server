## Wat moet v0.0.3 doen

### 1. WhatIf vóór elke deploy-stap (P-TECH-04)

Lees `Meta_Master/SHARED_INFRASTRUCTURE.md` opnieuw vóór ELKE shared-state-mutatie. Per `CLAUDE.md` § Deploy Protocol — niets impliciet.

### 2. Pre-deploy backup

```bash
ssh -i ~/.ssh/hetzner root@horsecloud55.ddns.net 'mkdir -p /root/backups/2026-06-XX_sunshine_predeploy'
# Backup huidige nginx config + systemd unit-files + iptables
```

### 3. Sunshine .deb install

```bash
wget https://github.com/LizardByte/Sunshine/releases/latest/download/sunshine-ubuntu-24.04-amd64.deb
apt install ./sunshine-ubuntu-24.04-amd64.deb
```

### 4. User + dirs

```bash
useradd -r -s /usr/sbin/nologin -d /var/lib/sunshine -m msx
mkdir -p /opt/steamdeckmsx/{bin,share,etc} /var/lib/steamdeckmsx/roms /var/log/sunshine
chown -R msx:msx /var/lib/steamdeckmsx /var/log/sunshine /var/lib/sunshine
install -m 755 deploy/sunshine/xvfb-wrapper.sh /opt/steamdeckmsx/bin/
install -m 644 deploy/sunshine/sunshine.conf.template /etc/sunshine/sunshine.conf
install -m 644 deploy/sunshine/apps.json /etc/sunshine/apps.json
install -m 644 deploy/systemd/steamdeckmsx-sunshine.service /etc/systemd/system/
```

### 5. openMSX-headless build

```bash
git clone --recursive https://github.com/cpaglebbeek/SteamDeckMSX_Stream_Server /opt/steamdeckmsx/repo
cd /opt/steamdeckmsx/repo/externals/openmsx
./configure --enable-headless --prefix=/opt/steamdeckmsx
make -j$(nproc) install
```

**Onbekend**: bestaat `--enable-headless` upstream? Eventueel fallback: openMSX met Xvfb-display (huidige apps.json-strategie).

### 6. systemctl enable + start

```bash
systemctl daemon-reload
systemctl enable --now steamdeckmsx-sunshine.service
systemctl status steamdeckmsx-sunshine.service
journalctl -u steamdeckmsx-sunshine.service -f
```

### 7. Firewall

```bash
ufw allow 47984/tcp comment 'Sunshine HTTPS'
ufw allow 47989/tcp comment 'Sunshine HTTP-PIN'
ufw allow 47990/tcp comment 'Sunshine web-UI'
ufw allow 48010/tcp comment 'Sunshine RTSP'
ufw allow 47998:48002/udp comment 'Sunshine RTP'
```

Hetzner Cloud Firewall web-UI: zelfde regels — beslis bron-restrictie (open 0.0.0.0/0 vs home-IP whitelist).
